# Max Plus TV

Projeto inicial Android em Kotlin + Jetpack Compose para uma interface de entretenimento com tema escuro e detalhes vermelhos.

## Estado atual
- Interface demonstrativa e navegação básica.
- Ainda não reproduz canais, filmes ou séries.
- A integração futura deve usar apenas fontes e conteúdos com autorização/licença.

## Compilação
O workflow `.github/workflows/build.yml` compila um APK de depuração pelo GitHub Actions após um push ou manualmente em **Actions**.
